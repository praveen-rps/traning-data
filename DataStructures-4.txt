Trees
-----
Tree is a non linear datastrcutre which represents the hierachy of data
Terminology

1. Node ---> A single lement in the tree that holds the data

2. Root ---> Top most node which has no predecesor or parent

3. Leaf Node ---> These are also terminal nodes , a node which has no successors

4. Intermediate nodes --> nodes which are in between root and leaf

5. parent / child -->  a node which is emerging from another node is child
                        a node has a child is parent

6. sub tree --> A tree formed by any set of nodes and its decendents

7. Height ---> Longest Path from root to a leaf

8. depth --> deistance from root to node


Diff Types of Trees
--------------------
1. BinaryTree -- Each nodes has at most 2 children

2. Binary Search Tree --It is also a binary tree but follows  a pattern
		left child values <= root <= right child values

3. Balanced Tree  -- height diff between left and right subtrees is minimal
		     (optimally zero)

Complexity  
insertion,deletion,search -- O(log n) --Avg case, O(n) --> Worst case


4. AVL Tree -- Self balancing BST, where the difference between the heights
of the left and right subtrees(balance factor) for every node must be atmost 1

to make any BST as AVL tree it will perform some rotations

1. LL Rotation - Left Left case
2. RR Rotation - Right Right case
3. LR - Left Right
4. RL - right left



5. Heap Tree    
		in a binary tree where Parent >= children  ( Max Heap tree)
		parent <= children (Min Heap Tree)

6. N-ary Tree -- A node that have more than 2 children


7. B-Trees or B+Trees   - Tree structures used in Database File Systems


8. Prefix trees or Trie trees --> Used to store strings like dictionaries
