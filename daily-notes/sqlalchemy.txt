To define any python class as Model follow the steps
----------------------------------------------------

1. define the base 
Base = declarative_base()

2. We have to define the model classes
class Employee (Base):
	__tablename__ = 'tbl_employees'
	id = Column(String(30), primary_key=True)
        name = Column(String(30))
        dept = Column(String(30))
        desg = Column(String(20))
	sal = Column(Float)
	address = Column(String(40))

class Department(Base):
	__tablename__ ='dept'
	deptno = Column(Integer,primary_key=True)
	name = Column(String(30))
	loc = Column(String(20))

3. we have to create any mysql engine to execute the queries
 create_engine("mysql+pymysql://<username>:<password>@localhost/<database>")

          echo=True)

4. create tables for models
Base.metadata.create_all(engine)

5.create a session for transactions
Session = sessionMaker(bind=engine)
