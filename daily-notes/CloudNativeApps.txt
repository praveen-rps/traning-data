Docker commands
---------------

1. Docker Management Commands - Manage docker images and containers

docker --version - used to display docker version installed 

docker images  -- used to see all images in the machine

docker ps - used to display all the running containers

docker ps -a : used to display all running and stopped containers

docker run -d <imagename/imageid> - to create a new container from the image

docker rm <containerid/name> -- to remove a container

docker rmi <imagename/id> -- to remove a image

docker pull <imagename> -- to pull or download an image from registry(dockerhub)


docker run -d -i -t -p host:continer --name <containername> <imagenamge/id>

docker stop <containername/id>

docker exec - used to go inside the container

docker exec -it <containername> /bin/sh

docker logs <containername>

docker inspect <conatinername>


docker push <account:image>
