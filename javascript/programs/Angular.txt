Angular is a typescript based front end framewor for developing single page application
this is managed by google.


Angular is used to build SPA that are dynamic, fast and responsive

2010 --> AngularJs

Angular 16,17 and 18---> standard versions for developing spa


What are the features of angular
-------------------------------

1. re usable component based arch
2. Two way binding -- automatically sync between data and UI
3. DI (Dependency Injection) -better modularity and testing
4. Builtin routing - easy to navigate between the components
5. Reactive Programming -- async processing
6. cross-platfrom -- works for web, mobile and desktop
