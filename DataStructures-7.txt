Horse has to cover all the squares in the given nxn square board wihtout
leaving any square un attended

(x,y) 8 possible positions

(x+2,y+1)
(x-2, y+1)
(x+1, y+2)
(x-1,y+2)
(x+2, y-1)
(x-2,y-1)
(x+1,y-2)
(x-1,y-2)

Algorithms steps:

1. start from an initial position (0,0)

2. initialize a board with all values as -1 (unvisited)
    array[8][8]

3.set the starting positiion as 0 (first move)

4. try all 8 possible moves from the current cell:
	if the next cell in board is not visited, move there and incremement the
	move count
	recrusive with new position

5. if all cells are visited ( move-count== n*n), print all the solution

6. if move is not possible at any position, backtrack to previous move and chose     
    another posistion and mark current one is unvisited

Time Complexity 

O(8*(n^2))


Rat in the a Maze Problem
--------------------------
Given N x N maze represented as a 2D grid, each cell has either 
1 -->> indicates the path
0 -->> indicates the block

The rat starts at the top-left corner(0,0) and wants to reach
the botto right corner (N-1,N-1)

The goal is to find all possible ways that rat can go from source to destination


Movement rules
---------------
1. move one square at a time
possible moves for it is :

Down --> D
Left --> L
Right --> R
Up --> U

Rat cannot revisit a cell


Algorithm
---------

1. start at (0,0)
2. Maintain:
	path: string of moves made ("DDRDR")
	visited: A matrix to mark all the visited nodes

3. for each move:
	3.1 Check if the next cell is within bounds, not visited and open(1)
	3.1 if so mark as visited, append the direction to the path and recurse
	3.2 after recursion, unmark visited cell 
4. if destination is reached, store the path and print it


N Queens Problem
----------------

1. place a queen row by row 
2. for each row, try placing a queen in every column
3. for each placement:
	3.1 check if it safe
		no queen in the same column		
		no queen in the same row
		no queen in left or right diagnols
4. if safe, move to the next row
5. if all rows are placed, store the positions
6. Backtrack when placing is not possible

Dynamic Programming
-------------------
define dp[i] as the length of the lis ending at index i

for  i in 1 to n-1:
	for j in 0 to i-1:
		if a[i] > a[j]:
		  dp[i]= max(dp[i], dp[j]+1)


Complexity : O(n^2)
